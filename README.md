# 跨境电商工作台

一个面向跨境电商团队的中文知识资料库网页原型，当前提供资料总览、关键词搜索、类型筛选、主题标签筛选和排序。

## 在线部署

仓库已配置 GitHub Actions Pages 工作流。首次使用时，请在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。之后推送到 `main` 会自动部署。部署地址格式为：

`https://shuishenlu-alt.github.io/cross-border-ecommerce-workbench/`

## 当前版本范围

- `index.html` 是无需构建工具的静态页面。
- 页面中的示例资料和统计数字是演示数据。
- 上传的原文件及资料信息保存在当前浏览器的 IndexedDB 中，刷新页面仍保留；可以编辑分类和标签、重新打开或删除资料。
- 本地浏览器存储不会同步到其他设备或团队成员，清理浏览器数据时可能丢失。
- 当前仓库没有后端、用户登录、团队权限或云端文件存储。仓库公开，页面示例数据也对外可见；请勿把敏感资料提交到仓库。

## 后续接入建议

1. 使用对象存储保存原始文档和视频，并配置上传大小限制、访问权限和生命周期。
2. 使用数据库保存标题、平台、类目、主题标签、文件地址、创建人和时间等元数据。
3. 增加登录与团队权限控制，再启用团队共享。
4. 为资料内容增加文本提取、视频转写、摘要、全文搜索和主题统计。

## 本地预览

直接用浏览器打开 `index.html` 即可查看原型。
